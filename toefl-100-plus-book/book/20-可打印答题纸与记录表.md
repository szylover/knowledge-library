# 20｜可打印答题纸与记录表

> **独立附册使用说明**：本附册只提供可复印、可手写的训练工具，不计入主教材 750 页正文。每次只打印当前需要的页；先写日期、材料编号和限时，再在练习结束后补全“证据/改法”栏。所有表格均为本书训练设计，不是 ETS 官方答题界面或评分表。

## 本册索引

| 页组 | 内容 | 建议用途 |
|---|---|---|
| 01—12 | 客观题答题卡 | 每次 20 题的小组练习 |
| 13—18 | CTW 记录纸 | Complete the Words 的证据与词形复盘 |
| 19—24 | 阅读证据表 | Read in Daily Life / Academic Passage |
| 25—30 | 听力精听表 | 对话、公告和学术短讲 |
| 31—36 | 作文纸 | 限时英文成稿 |
| 37—42 | 邮件与讨论规划表 | 写前取舍与写后自检 |
| 43—48 | 口语二录表 | 首录、反馈和同题重录 |
| 49—54 | 词汇卡 | 剪裁或折叠复习 |
| 55—60 | 错题表 | 建立可重做的错误库 |
| 61—84 | 24 周打卡 | 每周一页的执行与复盘 |
| 85—92 | 模考答题纸 | 8 套压缩模考的留档页 |

**通用标记**：`□` 未完成　`✓` 已完成　`R` 已复盘　`D1/D7` 分别表示 1 天后/7 天后重做。填写个人信息时只使用必要信息；若上传记录给陪练工具，先删除姓名、单位和联系方式。
