# TOEFL 750 页扩展版约束文档

## 1. 权威性

本文件是 750 页扩展任务的强制约束。后续主代理、子代理、审校和构建任务都必须先阅读并遵守本文件。若实现与本文件冲突，以本文件和用户最新明确指令为准。

批准实施后，将本文件复制到：

`D:\projects\knowledge-library\toefl-100-plus-book\CONSTRAINTS.md`

## 2. 页数目标

1. 主教材 `pdf/toefl-100-plus-book.pdf` 的实质正文不得少于 750 个 A4 PDF 页面。
2. “实质正文”只包括教学、原创练习、听力脚本、答案解析、模考和复盘指导。
3. 空白答题页、作文纸、打卡表、记录表和大面积留白不计入 750 页。
4. 可打印附册单独输出为 `pdf/toefl-100-plus-printables.pdf`，目标 50–100 页。
5. 合并版输出为 `pdf/toefl-100-plus-complete.pdf`，总页数应超过主教材。
6. 使用 `pdfinfo` 测量最终页数，不接受根据 Markdown 行数或字数推测。
7. 主教材少于 750 页时任务不得结束、不得发布、不得声称完成。

## 3. 禁止凑页数

禁止使用以下方式达到页数：

- 重复题目、重复解析或仅替换人名和数字；
- 同一内容的大量同义改写；
- 放大字号、扩大行距、缩窄版心或增加无意义分页；
- 大面积空白、单题单页或过量答题留白；
- 将 printable 页面计入正文；
- 复制现有教材、官方题目、回忆题或受版权保护的原文。

页数不足时，只能增加新的、经过答案审校的实质练习、解析、模考或教学内容。

## 4. 版本与目标学习者

- 适用 2026 年 1 月 21 日后 TOEFL iBT。
- 学习者是在职考生，每周可投入 10–12 小时。
- 当前无托福实考成绩，正在系统背词。
- 英文版 *Sapiens* 当前理解约 50%–60%。
- 已使用 ChatGPT 练习口语。
- 目标是建立旧分制 100+、新版约 5 分档所需能力，但不得保证完成教材即必然获得该成绩。

## 5. 语言与教学风格

- 中文讲解，英文题目、脚本、示例和练习。
- 采用“为什么—怎么做—示范—练习—解析—复盘”的渐进结构。
- 解释动机、类比、关键能力和应用流程。
- 适合自学，不依赖教师才能理解答案。
- 模板只作为思考框架，禁止鼓励僵化背诵。

## 6. 内容最低题量

- Complete the Words：至少 120 组原创短文。
- Read in Daily Life：至少 120 篇原创材料。
- Read an Academic Passage：至少 80 篇原创学术短文。
- Listen and Choose a Response：至少 300 题。
- Conversation / Announcement / Academic Talk：合计至少 160 篇原创脚本。
- Build a Sentence：至少 300 题。
- Write an Email：至少 80 题。
- Academic Discussion：至少 80 题。
- Listen and Repeat：至少 400 句。
- Take an Interview：至少 100 组连续采访。
- 完整原创模考：全书合计至少 8 套。

达到页数但未达到最低题量，仍视为未完成。

## 7. 题目与答案质量

### 客观题

每道客观题必须包含：

- 唯一正确答案；
- 文本或脚本证据；
- 干扰项为什么错误；
- 错因标签；
- 建议用时或难度标签。

### 听力

每篇听力材料必须包含：

- 可供 TTS 自然朗读的原创英文脚本；
- 题目和答案；
- 精听点；
- 语音识别或语用重点；
- 复述或跟读任务。

### 写作与口语

- 每个任务必须有任务完成要点和评分维度。
- 代表性任务必须提供高、中、低表现示例或逐句修改。
- 内部量表必须明确不是 ETS 官方分数换算。
- ChatGPT 反馈只作辅助，不可声称是官方评分。

## 8. 原创与版权

- 不复制 OG、Delta、TPO、*Sapiens*、真实考试、机经或回忆题原文。
- OG 仍用于官方题型、难度和评分校准，不能声称本书完美替代 OG。
- 本书可覆盖 Delta 的大部分渐进训练用途，但不能冒充 Delta 或 ETS 官方教材。
- “近期面经”只能用于概括能力趋势，不保留可识别题干和答案。
- 所有新增材料必须原创；若使用公开事实作为背景，应重新组织语言并避免长段引用。

## 9. 官方事实边界

- 官方题型、评分、时长和政策以 ETS 最新页面和 2026 规格文档为准。
- 必须区分计分项目、未计分项目和正式呈现题量，避免把不同口径写成固定范围。
- 自创的路由阈值、题量、计时、评分表和压缩模考必须标记为教学训练设计。
- 发布前再次核对 ETS 官方来源并记录核对日期。

## 10. 文件与仓库

- 工作仓库：`D:\projects\knowledge-library`
- 书籍目录：`toefl-100-plus-book/`
- Markdown 源稿：`toefl-100-plus-book/book/`
- LaTeX 构建文件：`toefl-100-plus-book/latex/`
- 构建脚本：`toefl-100-plus-book/scripts/`
- PDF 成品：仓库根目录 `pdf/`
- 不创建新的独立 GitHub 仓库。
- 不提交或修改与本书无关的 `ai-agent-book` 工作区改动。

## 11. 构建门禁

构建流程必须：

1. 按文件名顺序合并 Markdown；
2. 使用 Pandoc 和 XeLaTeX；
3. 自动处理长表格换行；
4. 生成可搜索文本的 PDF；
5. 使用 `pdfinfo` 读取正文页数；
6. 正文不足 750 页时返回失败；
7. 检查缺字、LaTeX 错误、超宽表格和损坏书签；
8. 抽查首页、目录、每章首页、中间题库页和最后页面。

## 12. 静态质量门禁

发布前必须确认：

- 无 TODO、TBD、占位符或空答案；
- 题号连续；
- 每道客观题都有答案；
- 答案键没有孤立编号；
- 不存在明显重复题干；
- Markdown 顶级标题唯一且顺序正确；
- 24 周路线引用的章节和模考真实存在；
- README 页数与 `pdfinfo` 一致；
- Git 提交仅包含 TOEFL 书相关文件。

## 13. 完成定义

只有同时满足以下条件才能结束：

1. 主教材正文 `>= 750` 页；
2. printable 附册已生成；
3. 合并版已生成；
4. 最低题量全部达到；
5. 新增题目答案覆盖完整；
6. 内容和版权终审完成；
7. 三份 PDF 均可打开、搜索、打印；
8. README 已更新；
9. 相关提交已推送到 `szylover/knowledge-library`；
10. 未包含无关工作区改动。
